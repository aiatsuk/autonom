# Autonom plugin payload

This package contains 24 portable skills for testing and debugging mobile apps
on Android and the iOS Simulator. Start with the `autonom` skill, then use
`project-router` to select the skills for your app and task.

The Autonom CLI is installed separately. Follow the
[installation guide](https://autonom.yatsuk.me/docs/install/) to install the CLI
and the device tools for your platform. Python 3.11+ is required; the iOS
Simulator also requires macOS and Xcode. Run `autonom doctor` to check which
capabilities are available before starting device work.

See the [documentation](https://autonom.yatsuk.me/docs/) for usage and platform
limits, and the [source repository](https://github.com/aiatsuk/autonom) for
installation, development, and the MIT license.
